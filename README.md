# 🎵 HacTuoc Music Bot - Zing MP3 24/7 on Render

Bot phát nhạc chuyên dụng từ Zing MP3 dành riêng cho HacTuoc School trên Discord.

## 🎧 Tính năng:
- Bóc tách luồng nhạc trực tiếp `.mp3` 128kbps từ Zing MP3.
- Hỗ trợ đầy đủ bộ lệnh prefix `m!`:
  - `m!play <tên bài / link>` (hoặc `m!p`): Phát nhạc / Thêm vào hàng đợi.
  - `m!skip` (hoặc `m!s`): Bỏ qua bài hát.
  - `m!pause` / `m!resume`: Tạm dừng / Tiếp tục.
  - `m!stop` / `m!leave`: Dừng phát và rời phòng.
  - `m!queue` / `m!q`: Xem hàng đợi.
  - `m!np`: Xem bài đang phát với nút điều khiển.
- Tích hợp máy chủ web kiểm tra sức khỏe (Health Check) chạy 24/7 trên Render Free Tier.
